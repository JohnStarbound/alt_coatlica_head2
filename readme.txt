This mod makes some cosmetic changes to the Coatlica race in order 
to make the race less human-like and more snake-like. 

The following changes have been made to the base mod:
1. Human skin has been replaced with colorable scales and secondary
scales.
2. Underbelly scales are now colorable, and you may pick from 
several preset colors. 
3. Some of the ability snakes apperances have been slightly 
modified. 
4. Highlights, shading and appearance tweaks.
5. Walk/run cycle animation tweaks to make the animation
feel more dynamic.
6. Bald hair option. 

That is about it. Thanks for downloading.
